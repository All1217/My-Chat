目前网上热门的第三方MCP服务广场，主要可以分为**大型综合类平台**、**专业精选导航站**、**云厂商平台**以及**开源社区精选列表**这几类。

### 🏛️ 大型综合类MCP广场

这类平台是MCP服务的“超级市场”，汇集的服务数量庞大，覆盖领域广。

*   **魔搭(ModelScope) MCP广场**：由阿里云发起，是目前**中国最大的MCP中文社区**。截至2025年6月，已上线**超过9200个**MCP Server，累计支持超过**16亿次**调用。它最大的特色是**独家首发**了**支付宝**（AI支付）和**MiniMax**（语音/视频生成）等重量级MCP服务。
*   **MCP.so**：由独立开发者创建，是**目前全球规模最大的MCP应用市场之一**。收录的MCP服务器数量已达**22680个**，以资源覆盖面广著称，并提供网页端的在线调试和Chat功能。

### 🎯 专业精选与导航平台

这类平台更侧重于服务的精选、评测和导航，帮助开发者发现高质量的MCP工具。

*   **Smithery.ai**：一个MCP能力扩展平台，收录了**7388个**MCP能力，并按**Web搜索、内存管理、浏览器自动化**等详细功能进行分类。
*   **PulseMCP**：一个MCP生态系统的**社区中心和每周新闻通讯平台**，每日更新，提供MCP用例、服务器、客户端和新闻的发现服务。
*   **Glama.ai**：专注于**生产级MCP服务器**的目录，提供官方认证、工具匹配和服务器评级，适合对稳定性和质量有高要求的开发者。
*   **Cursor Directory**：专门为**Cursor编辑器**用户设计的MCP资源和社区平台，用户可以在这里探索和生成规则、浏览MCP。

### ☁️ 云厂商与开发者平台

主流云服务商也纷纷推出了自己的MCP服务广场，方便开发者在其生态内使用。

*   **腾讯云MCP广场**：汇集了**腾讯官方和热门第三方MCP**，并提供MCP安全扫描、免费托管等服务。
*   **阿里云百炼**：阿里云的企业级大模型开发平台，其**插件市场**也支持MCP服务。
*   **百度MCP**：百度智能云千帆大模型平台也全面兼容MCP协议，其MCP服务发现平台除了第三方服务，还接入了**百度地图、百度网盘**等自家服务。
*   **华为云MaaS**：其“资产中心”也设有“MCP广场”，提供了包括**高德地图、美图影像**等在内的多种MCP服务。
*   **火山引擎MCP Servers**：被称为“大模型工具超市”，集成了大量支持MCP协议的优质工具。

### 📚 开源社区精选列表

对于喜欢自己探索的开发者，GitHub上有许多由社区维护的精选列表，是发现优质MCP服务器的宝库。

*   **[awesome-mcp-servers](https://github.com/wong2/awesome-mcp-servers)**：一个由社区维护的精选MCP服务器列表。
*   **[best-of-mcp-servers](https://github.com/tolkonepiu/best-of-mcp-servers)**：包含**400个**优秀的MCP服务器，并按项目质量评分排名。
*   **[Awesome-MCP-ZH](https://github.com/yzfly/Awesome-MCP-ZH)**：专为中文用户打造的MCP资源合集。

### 💎 总结

*   如果需要最全的资源，可以首选**魔搭ModelScope MCP广场**或**MCP.so**。
*   如果想寻找特定领域的高质量工具，**Smithery.ai**和**Glama.ai**等专业平台会更高效。
*   如果深度使用某家云服务，可以优先考虑其自家的MCP广场。
*   如果喜欢自己动手探索，GitHub上的**Awesome列表**是绝佳的资源库。
