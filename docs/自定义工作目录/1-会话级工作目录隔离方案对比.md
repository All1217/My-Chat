## 方案评估

### 核心架构问题（致命）

**`WorkspaceUtil` 是全局单例，`switchRoot()` 会同时影响所有请求。**

当前 `WorkspaceUtil` 是 `@Component`（Spring 单例），其 `workspaceRoot` 字段是可变状态。`ShellTool`（AI 的文件操作工具）通过 `resolveSafe()` 始终使用这个全局的 `workspaceRoot`。一旦会话 A 切换到目录 X，所有并发请求——包括会话 B、C——的文件操作都会错误地作用于目录 X。

**这意味着当前方案在单用户场景勉强可用，但在多会话/多用户场景下会产生数据错乱。**

### 当前代码已有部分实现，但有缺陷

前端 `ChatList.vue:129-151` 和 `ChatView.vue:129-151` 已有"打开目录"弹窗和 `handleConfirmDirectory`，但存在以下问题：

| 问题                                               | 位置                                 |
| -------------------------------------------------- | ------------------------------------ |
| 切换会话时 `currentWorkspace`（全局）不会随之变化  | `chat.ts` store                      |
| `createConversation` 没有传递 `workDir` 到后端     | `chat.ts:68`                         |
| `currentWorkspace` 是全局单值，不是 `per-session`  | `chat.ts:18`                         |
| 后端 `ChatSessions` PO **没有** `workDir` 字段映射 | `ChatSessions.java:14-39`            |
| 后端 `addConversation` 没有持久化 `work_dir`       | `ChatSessionsServiceImpl.java:34-40` |
| 后端 `ChatSessionVO` 没有返回 `workDir`            | `ChatSessionVO.java:9-21`            |
| 后端 `ChatSessionsDTO` 不支持更新 `workDir`        | `ChatSessionsDTO.java:8-19`          |
| DB 已有 `work_dir` 列但 Java 层完全未映射          | `schema.sql:60`                      |

### 优缺点

| 优点                           | 缺点                                                   |
| ------------------------------ | ------------------------------------------------------ |
| 用户体验好：可视化的目录上下文 | `WorkspaceUtil` 全局可变状态是竞态条件根源             |
| 与会话模型自然契合             | 需要重构整个文件操作链路，改动面大                     |
| 前端 UI 已有雏形，改动范围可控 | `ShellTool` 与 `WorkspaceUtil` 紧耦合，无法感知会话    |
|                                | 并发场景下后端无法区分"当前请求属于哪个会话的工作目录" |

### 建议的正确方案

**核心思路：废掉全局 `switchRoot()`，改为请求级传递工作目录。**

1. **后端：移除 `WorkspaceUtil` 的可变全局状态**。在 `FileController` 的每个文件操作请求中增加 `workDir` 参数（或通过请求头/拦截器传递），`WorkspaceUtil` 改为无状态工具类，每次调用时接收 `workDir` 作为参数。

2. **后端：若不想大改 `WorkspaceUtil`**，可以增加一个 `ThreadLocal` 存储当前请求的 `workDir`，在 `ChatHistoryController.selectConversation` 或一个专门的拦截器中根据 `conversationId` 查库设置。

3. **前端：`currentWorkspace` 改为派生自 `currentChat.workDir`**，切换会话时自动更新，并在切换时调用后端同步工作目录。
