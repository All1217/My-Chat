## 根因

`WorkspaceUtil.resolveSafe()` 已从 `WorkspaceContext` 正确计算出会话级 `root`，但后续路径解析仍写死使用 `workspaceRoot`：

```java
// 修复前（bug）
Path resolved = workspaceRoot.resolve(cleaned).normalize();
if (!resolved.startsWith(workspaceRoot)) { ... }

// 修复后
Path resolved = root.resolve(cleaned).normalize();
if (!resolved.startsWith(root)) { ... }
```

仅 **`my-chat-server/src/main/java/com/mychat/utils/WorkspaceUtil.java`** 中 `resolveSafe()` 的两处 `workspaceRoot` → `root`。调试埋点已全部移除。
