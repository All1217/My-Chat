#### 7 将知识库与AI结合起来

##### 核心思路

[市场主流方案对比]: ./知识库隔离查询方案对比.md

利用 Spring AI 的 **metadata 过滤机制**实现知识库隔离：

```
上传:  每个分片 segment 的 metadata 中写入 kbId
检索:  SearchRequest.filterExpression("kbId == '<xxx>'") 只查指定知识库
对话:  前端传 kbId → 后端按 kbId 检索 → 拼入上下文 → ChatClient 流式回答
```

官方文档明确支持此方式（`Filter.Expression` / 字符串过滤表达式），且 pgvector 实现完全兼容。

**3. 新文件 `RagChatController.java`**

```java
package com.mychat.controller;

import com.mychat.service.EmbeddingService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.memory.ChatMemory;
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;
import reactor.core.publisher.Flux;

import java.util.List;
import java.util.stream.Collectors;

@Slf4j
@RestController
@RequestMapping("/ai/ragChat")
@RequiredArgsConstructor
public class RagChatController {

    private final ChatClient chatClient;
    private final ChatMemory chatMemory;
    private final VectorStore vectorStore;

    /**
     * 基于指定知识库的 RAG 流式对话
     *
     * @param prompt  用户问题
     * @param chatId  会话 ID
     * @param kbId    知识库 ID（必填，用于隔离检索范围）
     * @param files   可选的多媒体文件
     */
    @RequestMapping(value = "/chat", produces = "text/html;charset=utf-8")
    public Flux<String> chat(
            @RequestParam("prompt") String prompt,
            @RequestParam("chatId") String chatId,
            @RequestParam("kbId") String kbId,
            @RequestParam(value = "files", required = false) List<MultipartFile> files) {

        // 1. 向量检索：只查指定知识库
        SearchRequest request = SearchRequest.builder()
                .query(prompt)
                .topK(5)                                    // 返回 top-5 最相关片段
                .similarityThreshold(0.5)                   // 相似度门槛，低于此值忽略
                .filterExpression("kbId == '" + kbId + "'") // ← 关键：按知识库过滤
                .build();
        List<Document> relevantDocs = vectorStore.similaritySearch(request);

        // 2. 拼接上下文
        String context = relevantDocs.stream()
                .map(Document::getText)
                .collect(Collectors.joining("\n\n---\n\n"));

        // 3. 组装 prompt（带上下文 + 历史）
        String ragPrompt = context.isBlank()
                ? prompt   // 没命中任何文档，走纯对话
                : "基于以下参考内容回答用户问题。如果参考内容不足以回答，请如实告知。\n\n"
                + "参考内容：\n" + context + "\n\n"
                + "用户问题：" + prompt;

        // 4. 流式调用 ChatClient（保持与 ChatController 一致的 thinking 标签处理）
        return chatClient.prompt()
                .user(ragPrompt)
                .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, chatId))
                .stream()
                .chatResponse()
                .map(response -> {
                    String content = response.getResult().getOutput().getText();
                    var metadata = response.getResult().getMetadata();
                    String thinking = (String) metadata.getOrDefault("reasoningContent", null);
                    StringBuilder sb = new StringBuilder();
                    if (thinking != null && !thinking.isEmpty()) {
                        sb.append("[THINKING]").append(thinking).append("[/THINKING]");
                    }
                    if (content != null && !content.isEmpty()) {
                        sb.append(content);
                    }
                    return sb.toString();
                });
    }
}
```

**三、数据流示意**

```
用户输入问题 + 选择知识库 "考试学习"
       ↓
fetch → /rag/ai/ragChat/chat?prompt=...&chatId=...&kbId=kb_001
       ↓
RagChatController
  ├─ vectorStore.similaritySearch(SearchRequest
  │     .query("..")
  │     .filterExpression("kbId == 'kb_001'")   ← 只查该知识库
  │     .topK(5))
  ├─ 拼接命中片段 → 构造 RAG prompt
  └─ ChatClient.prompt().user(ragPrompt).stream()
       ↓
流式返回 text/html
```

**四、注意事项**

| 要点          | 说明                                                         |
| ------------- | ------------------------------------------------------------ |
| **已有文档**  | 之前上传的文档缺少 `kbId` metadata，重新上传到知识库即可     |
| **topK 调优** | `topK(5)`、`similarityThreshold(0.5)` 按需调整，建议做成知识库级别可配置 |
| **思考标签**  | `[THINKING]...[/THINKING]` 处理与普通聊天一致，前端 `ChatBox.vue` 已有 `parseMessage` 处理 |
| **空结果**    | 未命中任何文档时走纯对话逻辑（`RagChatController` 已处理）   |
