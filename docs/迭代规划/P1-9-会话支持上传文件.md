# P1-9：会话支持上传文件

## 目标

用户在聊天输入框上传文件（图片/PDF/文本）→ 文件列表预览 → AI 分析 → 记录到聊天历史

---

## 技术调查

### Spring AI 多模态支持现状

从 Spring AI 2.0.0 [官方文档](https://docs.spring.io/spring-ai/reference/api/multimodality.html) 确认，当前明确支持多模态（图片）的模型：

- OpenAI（GPT-4V 等）
- Anthropic Claude
- Google Gemini
- Ollama（LLaVA 等）
- Mistral AI（Pixtral）
- AWS Bedrock Converse

**DeepSeek 不在支持列表中**，其 `DeepSeekChatModel` 文档中无任何多模态提及。向 DeepSeek 发送 `Media` 对象将导致 API 返回 400 错误。

### 现行实现的问题

`ChatController.multiModalChat()` 将所有文件统一转换为 `Media` 对象发给模型：

```java
List<Media> medias = files.stream()
    .map(file -> new Media(
        MimeType.valueOf(Objects.requireNonNull(file.getContentType())),
        file.getResource()
    ))
    .toList();
```

对 DeepSeek（纯文本模型）发送 `Media` 对象会导致调用失败。因此需要**按文件类型分叉处理**：

| 文件类型 | 处理方式 |
|---|---|
| 图片（jpg/png/gif/webp） | 发为 `Media` 对象，模型不支持时报错 |
| PDF | 服务端提取文本，拼入 prompt 上下文 |
| 文本（txt/md） | 读取内容，拼入 prompt 上下文 |

---

## 核心问题解答

### Q1：模型不支持图片时如何处理？

```
前端选择图片 → 后端收到 files 参数
  ├─ 检测到有图片文件 → 调用 multiModalChat()
  │    ├─ 模型支持图片（如 GPT-4V）→ 正常分析
  │    └─ 模型不支持图片（如 DeepSeek）→ API 报错
  │         └─ Flux.error() → 前端 onError 回调
  │              → ChatBox 显示 "当前模型不支持图片分析，已为您提取文本内容"
  └─ PDF/文本提取为上下文 → 无论模型都生效
```

**后端改动**：`ChatController.multiModalChat()` 中的图片 `Media` 发送失败时，catch 异常并通过 `Flux.error()` 返回友好提示。

**前端改动**：`ChatBox.vue` 的 `onError` 回调中区分错误类型 — 若为"不支持图片"类错误，弹 ElMessage 提示而非显示在消息列表。

### Q2：文件信息能否存入 `spring_ai_chat_memory`？

能。`spring_ai_chat_memory` 由 `MessageChatMemoryAdvisor` 自动写入，但仅存储**发给模型的消息**（即 `toolChatClient.prompt().user(prompt)` 的内容）。当前前端在 `messages.value` 中的文件信息是本地 UI 数据，不经过后端。

**方案**：将文件信息**拼入 user prompt 文本前缀**，随正常消息一起发给后端：

```
prompt = "📎 用户上传了以下文件：\n- 图表.png（2.3MB）\n- 报告.pdf（4.1MB）\n\n用户的问题：请分析这些文件"
```

这样 `MessageChatMemoryAdvisor` 自动将带有文件信息的完整 prompt 存入 `spring_ai_chat_memory`。

### 一、后端：`ChatController.java`

#### 改造 `multiModalChat()` — 按文件类型分叉处理

```java
private Flux<String> multiModalChat(String prompt, String chatId, List<MultipartFile> files) {
    // 1. 分离文件：图片 vs 文本文档
    List<MultipartFile> images = new ArrayList<>();
    List<MultipartFile> documents = new ArrayList<>();

    for (MultipartFile file : files) {
        String contentType = file.getContentType();
        if (contentType != null && contentType.startsWith("image/")) {
            images.add(file);
        } else {
            documents.add(file);
        }
    }

    // 2. 提取文档内容作为上下文
    String docContext = extractDocumentsContext(documents);

    // 3. 拼接最终 prompt（文件信息 + 用户问题）
    String fullPrompt = docContext.isEmpty()
            ? prompt
            : docContext + "\n\n用户的问题：\n" + prompt;

    // 4. 构建 ChatClient 请求
    var spec = toolChatClient.prompt()
            .system(buildWorkspaceSystemPrompt())
            .user(u -> {
                u.text(fullPrompt);
                // 图片作为 Media 附加
                for (MultipartFile img : images) {
                    try {
                        u.media(MimeType.valueOf(Objects.requireNonNull(img.getContentType())),
                                img.getResource());
                    } catch (Exception e) {
                        log.warn("跳过不支持的图片: {}", img.getOriginalFilename());
                    }
                }
            })
            .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, chatId));

    // 5. 流式调用
    Flux<String> result = spec.stream().chatResponse()
            .map(response -> {
                String content = response.getResult().getOutput().getText();
                var metadata = response.getResult().getMetadata();
                String thinking = (String) metadata.getOrDefault("reasoningContent", null);
                StringBuilder sb = new StringBuilder();
                if (thinking != null && !thinking.isEmpty()) {
                    sb.append("[THINKING]").append(thinking).append("[/THINKING]");
                }
                if (content != null && !content.isEmpty()) {
                    sb.append(content);
                }
                return sb.toString();
            });

    // 6. 错误兜底：模型不支持图片时返回友好提示而非崩溃
    return result.onErrorResume(e -> {
        String msg = e.getMessage() != null ? e.getMessage() : "";
        if (msg.contains("400") || msg.contains("unsupported") || msg.contains("not support")) {
            log.warn("模型不支持图片分析: {}", msg);
            return Flux.just("当前模型不支持图片分析，系统已提取文档中的文本内容供参考。");
        }
        return Flux.error(e);
    });
}

/**
 * 从上传的文本文档中提取文字内容，拼接为上下文提示
 */
private String extractDocumentsContext(List<MultipartFile> documents) {
    if (documents.isEmpty()) return "";

    StringBuilder context = new StringBuilder("📎 用户上传了以下文件，其内容已提取供参考：\n");
    for (MultipartFile file : documents) {
        String filename = file.getOriginalFilename();
        if (filename == null) continue;
        try {
            String text;
            if (filename.toLowerCase().endsWith(".pdf")) {
                text = extractPdfText(file);
            } else {
                text = new String(file.getBytes(), StandardCharsets.UTF_8);
            }
            if (!text.isBlank()) {
                context.append("\n--- ").append(filename).append(" ---\n");
                // 截断过长内容（单文件最多 50KB）
                if (text.length() > 50_000) {
                    text = text.substring(0, 50_000) + "\n\n... [内容过长已截断]";
                }
                context.append(text).append("\n");
            }
        } catch (Exception e) {
            log.warn("提取文档内容失败: {}", filename, e);
            context.append("\n--- ").append(filename).append("（内容提取失败）---\n");
        }
    }
    return context.toString();
}

/**
 * 使用已有 PDFBox 提取 PDF 文本
 */
private String extractPdfText(MultipartFile file) throws Exception {
    try (PDDocument doc = PDDocument.load(file.getInputStream())) {
        PDFTextStripper stripper = new PDFTextStripper();
        return stripper.getText(doc);
    }
}
```

#### Script — 新增文件上传逻辑

```ts
import { Close } from '@element-plus/icons-vue'

// ---------- 文件上传状态 ----------
const fileInputRef = ref<HTMLInputElement>()
const selectedFiles = ref<File[]>([])

const ALLOWED_IMG_TYPES = ['image/jpeg', 'image/png', 'image/gif', 'image/webp']
const ALLOWED_DOC_EXT = ['.txt', '.md', '.pdf']
const MAX_FILE_SIZE = 10 * 1024 * 1024    // 10MB
const MAX_FILE_COUNT = 10

function triggerFilePicker() {
    fileInputRef.value?.click()
}

function handleFileSelect(event: Event) {
    const input = event.target as HTMLInputElement
    const rawFiles = Array.from(input.files ?? [])
    input.value = ''   // 清空，允许重复选同一文件

    for (const file of rawFiles) {
        if (selectedFiles.value.length >= MAX_FILE_COUNT) {
            ElMessage.warning(`最多上传 ${MAX_FILE_COUNT} 个文件`)
            break
        }
        const ext = '.' + file.name.split('.').pop()?.toLowerCase()
        if (!ALLOWED_IMG_TYPES.includes(file.type)
            && !ALLOWED_DOC_EXT.includes(ext)
            && !file.type.startsWith('text/')) {
            ElMessage.warning(`不支持的文件类型: ${file.name}`)
            continue
        }
        if (file.size > MAX_FILE_SIZE) {
            ElMessage.warning(`文件过大（最大 10MB）: ${file.name}`)
            continue
        }
        if (selectedFiles.value.some(f => f.name === file.name && f.size === file.size)) {
            continue   // 去重
        }
        selectedFiles.value.push(file)
    }
}

function fileIcon(file: File): string {
    if (file.type.startsWith('image/')) return '🖼️'
    if (file.type === 'application/pdf' || file.name.endsWith('.pdf')) return '📄'
    return '📝'
}

function formatFileSize(bytes: number): string {
    if (bytes < 1024) return bytes + ' B'
    if (bytes < 1024 * 1024) return (bytes / 1024).toFixed(1) + ' KB'
    return (bytes / (1024 * 1024)).toFixed(1) + ' MB'
}
```

#### Script — 修改 `sendMessage()` 和 `startStreaming()`

```ts
async function sendMessage() {
    const text = inputText.value.trim()
    if (!text || isStreaming.value) return

    // 若有文件，构造文件信息前缀
    let fileContext = ''
    if (selectedFiles.value.length > 0) {
        fileContext = '📎 上传了以下文件：\n'
            + selectedFiles.value.map(f =>
                `- ${fileIcon(f)} **${f.name}**（${formatFileSize(f.size)}）`)
                .join('\n')
    }

    // 推文件信息消息 + 用户文字消息（均作为 USER 类型）
    if (fileContext) {
        messages.value.push({ text: fileContext, messageType: MessageType.USER })
    }
    messages.value.push({ text, messageType: MessageType.USER })
    inputText.value = ''
    scrollToBottom(true)

    // 拼接发送给后端的完整 prompt（文件信息 + 用户问题）
    const fullPrompt = fileContext
        ? `${fileContext}\n\n用户的问题：\n${text}`
        : text

    let chatId = chatStore.currentChatId
    if (!chatId) {
        chatId = generateChatId()
        isLocalNewChat = true
        await chatStore.createConversation(chatId, chatStore.kbId ?? undefined)
    }

    const filesToSend = selectedFiles.value.length > 0 ? [...selectedFiles.value] : undefined
    selectedFiles.value = []

    startStreaming(fullPrompt, chatId, filesToSend)
}

function startStreaming(prompt: string, chatId: string, files?: File[]) {
    isStreaming.value = true
    streamingContent.value = ''
    autoScrollEnabled.value = isAtBottom.value

    stopStreamingFn = streamChat({
        prompt,
        chatId,
        kbId: chatStore.kbId ?? undefined,
        files,
        onMessage: (chunk) => {
            streamingContent.value += chunk
            scrollToBottom()
        },
        onComplete: () => {
            messages.value.push({
                text: streamingContent.value,
                messageType: MessageType.ASSISTANT,
            })
            isStreaming.value = false
            streamingContent.value = ''
            stopStreamingFn = null
            scrollToBottom()
        },
        onError: (error) => {
            // 区分"模型不支持图片"和其他错误
            if (error.message?.includes('不支持图片') || error.message?.includes('400')) {
                ElMessage.warning('当前模型不支持图片分析，已提取文档文本内容')
                // 仍然将已有内容展示给用户
            }
            messages.value.push({
                text: `抱歉，请求出错：${error.message}`,
                messageType: MessageType.ASSISTANT,
            })
            isStreaming.value = false
            streamingContent.value = ''
            stopStreamingFn = null
            scrollToBottom()
        },
    })
}
```

## 数据流与记忆持久化

```
用户选文件 + 打字 → 点击发送
  │
  ├─ 前端 messages 推入 2 条 USER 消息（文件信息 + 文字）
  ├─ 拼装 fullPrompt = "📎 上传了：xxx\n\n用户的问题：yyy"
  ├─ FormData.append('prompt', fullPrompt)
  │   + FormData.append('files', 原始文件)
  │
  └─ POST /ai/normalChat/chat (multipart/form-data)
       │
       ├─ 后端 ChatController.multiModalChat()
       │   ├─ 图片 → Media 对象（模型不支持时 Flux.error 兜底）
       │   ├─ PDF → PDFBox 提取文本 → 拼入 system context
       │   └─ txt/md → UTF-8 读取 → 拼入 system context
       │
       ├─ MessageChatMemoryAdvisor
       │   └─ 将 fullPrompt 存入 spring_ai_chat_memory
       │      （包含文件信息 + 用户问题）
       │
       └─ Flux 流式返回 → ChatBox 渲染
```
